📝 Opis projekta

TaskMaster2 je moderna aplikacija za upravljanje projektov in nalog, zasnovana za enostavno sodelovanje ekip. Aplikacija omogoča ustvarjanje projektov, dodajanje nalog, dodeljevanje ekipnih članov, sledenje napredku in komentiranje.

Projekt vključuje frontend (React + TypeScript), backend (Node.js + Express) in popoln CI/CD pipeline z avtomatskim testiranjem, gradnjo Docker slik, deployment na Render in GitHub Pages za dokumentacijo.

🛠️ Tehnologije

React TypeScript Node.js Express Docker GitHub Actions Jest Render
